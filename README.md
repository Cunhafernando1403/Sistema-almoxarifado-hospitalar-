# Sistema de Gerenciamento de Almoxarifado Hospitalar

## 📋 Sobre o projeto

Este projeto tem como objetivo desenvolver um sistema para auxiliar no gerenciamento de um almoxarifado hospitalar, facilitando o controle dos materiais armazenados, das entradas e saídas de produtos e da distribuição de suprimentos para os setores do hospital.

A proposta é contribuir para uma organização mais eficiente do estoque, reduzir falhas de registro e facilitar o acompanhamento da disponibilidade dos materiais.

## 🎯 Objetivos

- Organizar o cadastro dos materiais do almoxarifado.
- Registrar entradas e saídas de produtos.
- Acompanhar os níveis de estoque.
- Identificar materiais que precisam de reposição.
- Consultar o histórico de movimentações.
- Apoiar a distribuição de materiais para os setores hospitalares.

## ⚙️ Funcionalidades previstas

- **Cadastro de materiais:** descrição, código, unidade de medida e outras informações relevantes.
- **Controle de entradas:** registro de recebimentos e quantidades adicionadas ao estoque.
- **Controle de saídas:** registro das retiradas e dos setores solicitantes.
- **Consulta de estoque:** visualização das quantidades disponíveis.
- **Estoque mínimo:** sinalização de materiais que precisam ser repostos.
- **Relatórios:** consulta das movimentações e da posição do estoque.

> As funcionalidades acima representam o escopo planejado e poderão ser ajustadas durante o desenvolvimento.

## 🏥 Público-alvo

O sistema é pensado para uso por profissionais responsáveis pelo almoxarifado e pelo abastecimento dos setores de uma unidade hospitalar.

## 🔒 Observações sobre segurança

Em uma futura implementação, o sistema deverá considerar controle de acesso, integridade dos registros e rastreabilidade das movimentações. Dados reais de pacientes ou informações confidenciais não devem ser incluídos neste repositório.
